    How to read the map
    Size
    A star grows with each recall.
    Brightness
    Newer memories are brighter.
    Hollow ring
    A memory that was never recalled.
    Gold arc
    A topic shared by two projects.
    Cyan link
    Similar memories, found from embeddings.
    Claude core
    The white star in the centre: where recalls and saves start.
    Sparks
    Gold is a recall, teal is a save or an update, red is a forget.
    Moons
    Knowledge extracted from a memory, orbiting its star once you click it. A faint wide ring marks a star that has some.
